# Demo Script (10 minutes)

## Setup (2 min)
1) Log in to TaskPilot
2) Connect Google Workspace + Slack + Stripe
3) Verify #finance exists in Slack

## Demo flow (8 min)
### Step A — Natural language task (3 min)
- Paste prompt: Weekly revenue report
- Show plan preview and explain approvals (WRITE steps gated)
- Approve & Run

### Step B — Observability (2 min)
- Open Runs dashboard
- Show step timeline, inputs/outputs, artifact (PDF), and Slack post link

### Step C — Save + schedule (3 min)
- Click “Save as workflow”
- Name: Weekly Revenue Report
- Schedule: every Monday 9am local
- Run a test with custom dates

## Key value points to narrate
- No drag-and-drop; NL → structured plan
- Reliable execution with retries and resumption
- Safe approvals before write actions
- Audit trail for compliance and trust
